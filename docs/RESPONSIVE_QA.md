# 响应式布局验收

验证日期：2026-10-16。使用 Chromium 实际操作界面，配合布局尺寸检查和截图复核。测试采用独立临时 SQLite 数据库，使用长账户名、无空格的长资产名、较大金额及长备注；没有读取个人投资记录。

## 覆盖范围

核心流程覆盖 42 种页面状态、714 组视口检查：

| 区域 | 检查内容 |
| --- | --- |
| 工作台 | 基金、股票、隐藏资产预览、空账户，以及展开的资产导航 |
| 账户 | 账户列表、重命名、创建入口和整库备份导入预览 |
| 资产 | 添加基金/股票、跌幅阈值、同步确认、手工净值/股价、隐藏确认 |
| 历史行情 | 基金净值、股票价格和包含 OHLC 列的历史表格 |
| 交易 | 基金/股票的买入、卖出，以及两种资产的交易编辑 |
| 分红与公司行为 | 新增和编辑现金分红、红利再投、送股、转增及股息税 |

补充检查包括资产菜单与交易菜单的贴边定位、图表提示框及其隐藏后的页面宽度、200% 根字号、日期选择器、搜索快捷键、无搜索结果、加载层及表格翻页。批量导入组件另以独立预览验证窄屏与短窗口布局，并检查长错误提示。

## 验收标准与复核方法

1. 比较文档实际宽度与视口宽度，检查工作区、统计卡片、表单、按钮组和弹窗的实际滚动宽度；页面不产生横向溢出，标签和值不重叠。
2. 窄屏下展开资产列表、搜索并切换基金/股票；选中资产后列表收起。搜索快捷键需要先展开列表，再聚焦搜索框。
3. 表格只在自己的容器内横向滚动，交易操作列保持在右侧；横向和纵向滚动后仍可打开编辑菜单。
4. 逐个打开弹窗，改变屏幕宽高，并滚动到末尾，检查关闭、取消和提交按钮可访问。
5. 在手机横屏和短桌面窗口中打开日期选择器及操作菜单，检查浮层全部处于视口内。
6. 在图表边缘触发提示框，移动鼠标隐藏，再缩窄窗口；可见提示框不越界，隐藏提示框不撑开页面。
7. 将根字号放大到 32px（默认 16px 的 200%），复核页面、录入弹窗和日期选择器。
8. 延迟临时环境的资产列表响应，验证加载层始终覆盖当前窗口，加载完成后恢复交互。

表格内的滚动用于保留完整交易字段；大段备注和名称按可用空间换行。布局断点由工作区自身宽度决定，桌面侧栏占用的空间不会被误计入卡片可用宽度。

验证环境为浏览器视口模拟；系统软键盘和不同移动设备浏览器的行为需在相应设备上继续验证。
